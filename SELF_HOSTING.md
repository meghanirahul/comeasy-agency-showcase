# Self-hosting Comeasy

This is a server-rendered React 19 website using TanStack Start and TanStack Router, not React Router. The current Lovable deployment configuration targets its managed runtime; it is not a ready-made Node server package.

To host on your own server, export the source and follow the current TanStack Start deployment guide for your server environment, adapting the deployment adapter outside Lovable. Keep the existing route files, React components and styling intact. Do not deploy only the browser assets if server-side rendering is required.

- Lovable self-hosting: https://docs.lovable.dev/tips-tricks/self-hosting
- TanStack Start hosting: https://tanstack.com/start/latest/docs/framework/react/guide/hosting
- Enquiries currently open an email draft; no hosted email service or database is required.
- Uploaded portfolio and team images reference Lovable Assets; retain access to those URLs or migrate the media to your own hosting when exporting.
- Two developer portraits are AI-generated illustrations. Replace them with real team photos and verified names before presenting them as actual employees.

No custom-server deployment has been performed or verified in this project.
